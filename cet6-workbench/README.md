# 六级冲刺台（CET-6 Study Workbench）

面向 **2026 年 12 月 12 日** 全国大学英语六级（CET-6）冲刺备考的个人学习工作台。基于 **417 → 500**（听力 **≥150** 保底、写作翻译高杠杆提分、阅读 200+ 护盘）的目标预置 17 天节奏，所有进度与记录持久化在浏览器 `localStorage`，支持 JSON 导入导出。

## 本地运行

```bash
cd cet6-workbench
npm install
npm run dev
```

默认访问地址：`http://127.0.0.1:5173`

## 生产构建与检查

```bash
npm run typecheck
npm run build
npm run preview
```

## 核心模块

1. **今日台与分数驾驶舱（Score Cockpit & Hero）**：倒计时至 12 月 12 日、连续打卡统计、今日唯一核心任务（可自定义并一键直达对应训练），以及 417 → 500 总分与听力/写作翻译/阅读三板块分差刻度条（含听力 150 底线标尺，可随时校准）。
2. **17 天冲刺日程（Daily Plan）**：11 月 25 日至 12 月 11 日三阶段每日清单，按“听力保底 → 写译提分 → 阅读护盘”排序，支持勾选完成、自定义增删任务与分日进度总览。
3. **专项训练台（Section Drills）**：
   - **听力保底**：长对话 / 篇章 / 讲座 / 精听限时计步器（含结束轻提示音）、每日听力打卡与估算分换算、六大高频陷阱标坑清单、考场速记符号卡。
   - **写作与翻译**：作文与汉译英双题库、点击即插入的三段式高分结构模板、实时英文字数监控与自动保存练笔区、对标六级 15 分原始分 / 106.5 换算分的 6 项评分自检表。
   - **阅读提速**：仔阅 / 长篇匹配 / 选词填空配速计时与分段打点（Lap），以及与总错题本联动的阅读错题速记。
4. **错题本与语料库（Wrong-Book & Phrase Bank）**：按板块/掌握状态筛选搜索的错题复盘本，以及带“遮挡释义自测”模式的高频词汇与同义替换库。
5. **模考轨迹追踪（Mock Exam Tracker）**：记录历次模考总分与分项成绩，自动绘制 417 → 500 总分曲线与听力 ≥150 底线曲线，并联动更新首页驾驶舱。
6. **校准与备份（Calibration & Backup）**：随时编辑基线/目标分数与考试日期，支持 JSON 一键导出备份、导入恢复与重置默认种子数据。
